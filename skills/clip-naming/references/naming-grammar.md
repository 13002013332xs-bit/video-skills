# 命名语法（从用户已有 1000+ 个素材名里总结）

## 第 0 条：先客观看画面，再套命名规则（2026-09-17 血泪教训）

模型很容易被"背景知识"带偏。曾经在提示词里写"这是磁吸灯素材，它用来吸零件"，
结果一整批**指甲油瓶滴胶**的镜头全被命名成"吸+细钉子（特）"——完全错。

正确顺序：

1. **先说你真看到什么**：画面主角是谁（手？指甲油瓶？管钳？磁吸灯？），出现哪些东西，时间线上发生了什么。
2. **再判断它是不是在做产品功能演示**：是 → 走磁吸灯词表；不是 → 照实描述（例如 `指甲油瓶滴胶包裹螺母`）。
3. **画面里没有的东西绝对不许写**。

真实例子（同一批素材的三种命名，只有第三行是对的）：

| 命名方式 | 结果 |
|---|---|
| 硬套产品词表（错） | `吸+细钉子（特）`、`照（特）` |
| 只靠词表拼装（半对） | `指甲油瓶+滴胶+拉丝+胶丝（特）` |
| **先客观描述再命名（对）** | `指甲油瓶滴胶包裹螺母（特）` |

## 结构

```
主体/数量 + 动作 + 结果/展示 +（视角或场景）
```

- 中位长度 9–10 字，范围 2–24 字；**目标 0–15 字**
- 连接符：
  - `+` 连续动作（`伸+吸+展`、`收+后吸住`）
  - `×` 先做无用动作、之后才用产品（`用管道捡钥匙×后用灯（下水道）`）
  - `&` 并列（`多次伸缩&弯曲+展灯`）
- 括号补**视角/场景/道具**：`（特）(俯)（侧）（跟随）（下到大）（发动机）（蓝铁架）（黄刻+沙发）`
- 同一动作多条时在名字后加 `2`、`3`（不要用"副本"）

## 通用简写

| 画面 | 写法 |
|---|---|
| 拉长/伸长 | `伸` |
| 收回/缩短 | `缩` |
| 点亮 | `开灯` |
| 给人看 | `展` |
| 特写视角 | `（特）` |
| 磁吸功能示意但没吸到东西 | `假吸` |
| 用产品尾部 | `后吸` / `后吸住` |
| 用产品底部 | `底部吸` / `底磁` |
| 照亮暗处 | `照亮` / `照深处` |
| 引导下单 | `引下单` |
| 演戏/剧情 | 名字里体现动作（`搞掉`/`敲一敲`/`涂水不膨胀扔掉`），分类归"演戏开头" |

## 各产品词表

**磁吸灯**：吸、吸住、吸出、伸/弯、缩、展/展示、开灯、照亮、照深处、底部、后吸住、假吸、指功能、特写
　主体写法：`单灯`/`双灯`/`多灯`/`3灯`/`8只`

**多功能笔**：双支、双色、黄笔/黑笔、刻字、触控笔、旋转出笔、开瓶器、螺丝刀、敲一敲、展示
　主体写法：`双支`/`4只`/`6只`/`黄笔`/`黑笔`

**肌理画**：涂水、膨胀、平面→立体、涂色、挂树枝、平铺桌面、盘子
　主体写法：动物名（猫/螃蟹/蘑菇/恐龙…）+ 数量（`6动物`）

## 实例（用户的真实名字）

- `单灯后吸住+拉远双灯（蓝铁架）`
- `吸深处细钉子（特）`
- `指前磁+伸+吸深处钉子`
- `底部吸出+向上伸+弯+灯`
- `收+后吸住引下单`
- `双色双支笔头展示`
- `给平面小猫涂水不膨胀扔掉`
- `平面螃蟹拉后到立体螃蟹`
- `6动物+展多未涂纸下单（结尾）`

## 零件要写到"具体形态"（用户明确要求）

不要写笼统的 `零件`／`钉子`／`东西`，要用**修饰词 + 零件名**。修饰词按形状/大小/特征：

`细 / 粗 / 长 / 短 / 大 / 小 / 带帽 / 带把 / 多层 / U型 / 弯`

**钉子家族**（用得最多）：`细钉子`(24) > `粗钉子`(5) > `带帽钉子`(2)、`长钉子`、`粗长钉子`、`弯长钉子`、`U型钉`、`小钉子`
**套筒家族**：`套筒`(47) > `带把套筒`(12) > `长套筒`、`多层套筒`、`细带把套筒`
**扳手家族**：`扳手`(47) > `橙扳手`、`短扳手`、`长扳手`、`车底扳手`
**钥匙家族**：`钥匙`(44) > `柜子缝隙钥匙`、`沙发底钥匙`
其他：`锤子`、`重物`、`铁桶`、`螺丝`、`圆片`、`圆筒`

**位置也带上**（放括号里）：`（车底）侧`、`（深处）`、`（缝隙）`、`（发动机）`、`（洗手池）`、`（下水道）`、`（柜子）`

| 笼统写法（不要） | 用户的写法（要） |
|---|---|
| 吸零件（特） | `吸深处细钉子（特）` |
| 吸钉子+展示 | `吸带把套筒+微展示（特）` |
| 后吸+照亮 | `后端吸住+照深处钥匙（有放大）` |
| 吸扳手 | `吸出短扳手+展示` |

## 起名时不要

- 不写"这是…"、不写句子、不加书名号
- 不用模型自己的形容词（"漂亮的""令人惊叹的"）
- 不杜撰画面上没有的东西；看不清就用更泛的词（`多零件` 而不是硬猜 `套筒`）
