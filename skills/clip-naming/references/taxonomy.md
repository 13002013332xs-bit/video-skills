# 分类判定规则（用户口述）

六个类目，按"这段在整条片子里的位置 + 用产品的哪个部位"判：

| 分类 | 判定 |
|---|---|
| **开头/演戏开头** | 有剧情动作：搞掉零件、敲一敲、爸爸扒拉灯、涂水不膨胀就扔掉、假装失手 |
| **开头/寻常开头** | 直接展示开场：打开包装、拿出来、123 展灯、双色双支展示 |
| **中间/前端** | 用产品**前端**做事，细分：<br>① 纯吸：单纯用前端吸出零件<br>② 吸+展示：吸出来后展示吸到了什么<br>③ 指功能+假吸：指前端功能、产品深入但没吸出东西<br>④ 特写：视角是特写（拍前端吸东西）<br>⑤ 照+吸+展：先照深处/掉落的零件，吸出来，再展示<br>⑥ 准备前吸：产品深入准备吸，但还没吸出来 |
| **中间/后端** | 用产品**后半部分**：后吸、后吸住后照亮深处 |
| **中间/中部** | 展示**前后端功能**或**夹子**——不属于前端也不属于后端的中间片段 |
| **结尾** | 收灯/关灯/放回 + 引导下单（名字里带 `引下单`/`下单`） |
