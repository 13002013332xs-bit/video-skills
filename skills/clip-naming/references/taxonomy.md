# 分类入口：先选产品，再按该产品规则归类

分类层次为产品 → 素材用途大类 → 产品细类/原表小节。相同功能词可能出现于不同用途，结合整段主要内容判断。

| 产品 | 大类与细类入口 |
|---|---|
| 磁吸灯 | 开头：演戏/寻常；中间：前端、中部、后端及功能组合小节；结尾：可有/无引下单。详见该产品专用文件。 |
| 多功能笔 | 开头：演戏/寻常等当批类别；功能素材按真实表中的颜色款式组和功能小节；结尾按收束用途。展买一送一按该产品已确认条件判断。详见该产品专用文件。 |
| 肌理画 | 已观察到演戏/正常开头、动物图案功能组、空镜/配件、结尾；具体个人规则尚待实片校准。 |
| 多功能锤 | 尚无已确认分类，先学该产品来源与实片。 |

产品命名文件路径从 `products.json` 读取；新增产品依其专用参考归类，不套磁吸灯前端/中部/后端。

## 飞书位置

操作前核对当批真实表头、合并区域及格内小节，不固定列号。历史分类索引只作来源线索，不能直接证明本次位置和表结构。名字中的同义词不构成合并历史小节的授权。

新片按学到的画面用途归类；旧素材选片保留其原表实际来源。历史集中区、错放和旧命名不能成为新批次集中堆放的模板。

“已成片”区域不接收未剪原素材。待确认条目在清单中单列，保存原片，不臆造正式类目或跳过条目。
