# 磁吸灯：已确认的个人命名与分类

依据2026-10-20至21日实片校准及21条新素材复核；新画面继续按具体分歧校准。

## 功能与用词

- 主要功能：灯、灯笼、前端磁性、后端磁性、拉长、弯曲。正面照射叫灯，拉开灯头露出一圈白色发光部分叫灯笼；灯笼拉开与伸缩杆拉长分别看实际动作。
- 片中实际发生吸附写“后吸住”；开场已经后端吸住、后面才拉长等，按用户例子写“已后吸住”。不把“已”加到所有后吸镜头。
- 灯原本已弯，片中只是转动照射方向，写“转”，不补“弯”；始终亮着不补“开灯”。用户完整名字：`后吸住+转+照亮深处（发动机）`。
- `准备吸`与`假吸`在本产品里是用于衔接后续吸取特写的同义表达，覆盖早先认为两者有区别的说法；未带出物品不写成吸出、失败或造假。原表不同历史小节仍保留。
- 指功能时用`指前端磁性`，不用旧简写“指前磁”。
- 吸起后稍向外抬起并停一下可叫`微展示`；已确认完整名`吸出深处细钉子+微展示（发动机）`。先看清实际吸取结果。
- `双灯`指两只磁吸灯，灯是产品简称。

## 相似素材如何区分

- 大量前吸钉子、后吸锤子的片段，用钉子粗细/直弯、锤子颜色等真实特征区分。用户指认的金色细螺纹物叫`细钉子`；该例锤柄黑色叫`黑锤子`，锤头银色不改变叫法。不扩大为所有螺纹物都叫钉子。
- 场景保留用于区分重复功能：发动机、空调机、可辨认背景等按画面选；特写也可写入场景括号。
- 用户2026-10-21纠正后的完整名字：
  - `手捡不到细钉子（发动机铁板特写）`
  - `手捡不到细钉子（发动机黑盒特写）`
  - `已后吸住+拉长灯笼（发动机双灯）`
- 上述为原作者纠正后的学习样例，不据此操作原作者的文件或素材表。当前命名以纠正后的表达学习。

## 分类

| 大类 | 细类/小节方向 |
|---|---|
| 开头 | 演戏开头、寻常开头 |
| 中间/前端 | 纯吸、吸+展示、指功能+假吸、准备吸/准备前吸、特写、照+吸+展 |
| 中间/中部 | 伸/灯/弯组合；伸弯灯与假吸、吸+展示、照+吸+展组合；前后端功能组合；夹子 |
| 中间/后端 | 后吸、后吸+照亮、后吸+伸+照亮等 |
| 结尾 | 收束/展示/引导购买，按原表可细分有引下单、无引下单 |

- 演戏开头正常写动作，一般不加演戏二字。已确认例子`扳手打掉套筒+手捡不到（发动机）`。
- 向下指常叫引下单，但指深处目标物不能仅凭方向归结尾；无下指也可能是结尾。
- 归类看整段主要用途，不只看第一个动作。21条中第18条先拆盒，后吸车盖、拉长弯曲、前吸扳手并展示，用户明确归`中间→中部→伸弯灯＋吸＋展示`。仅分类获确认，不将助手候选完整名字标成逐字通过。
- 看到“吸”不一律归前端，看到“拆盒”不一律归寻常开头。功能组合按对应小节。
