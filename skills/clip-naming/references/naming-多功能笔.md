## 二、命名规律（逐条从原格名看出来的）

### 通用句式

`动作/主语 + 功能部位 + （款式+机位）`

- **款式**写在括号里：`黄`、`黑`、`黄刻`（黄色+刻字）、`黑笔芯`
- **机位/背景**也写进同一个括号：`（黄刻+摇脚）`、`（黑+沙发）`、`（黑+俯）`
- 动词优先用：`展 / 展示 / 旋转出 / 旋出 / 拔出 / 掉出 / 点 / 指 / 展开 / 开灯 / 照亮`
- 收尾类直接以 `结尾` 或 `引下单` 收在名字里

## 四、拿不准时

- 先看**款式**（黄/黑）→ 再看**功能部位**（笔身/笔芯/灯/水平仪/开瓶器+支架/触控笔/螺丝/刻度/多个功能展示）
- 是开场戏 → `演戏开头`；是直接展示开场 → `寻常开头`；是收尾/引下单 → `结尾`
- 仍拿不准 → 放 `0_新片丢这里`，在确认清单里标「待确认」问用户，不要硬猜
