# 多功能笔：已确认的个人命名与分类

依据原作者2026-10-20至21日17轮实片校准；较新纠正优先于旧库归纳。此处为可沿用的个人风格预设；接收者使用自己的素材表和登录权限，执行时核对真实工作表与当批结构，不固定历史批次列号。

## 命名与款式

常用结构：`实际功能/关键动作（颜色款式+背景）`。

- `黄`、`黑`、`黄刻`区分颜色款式；黄刻是黄色刻字款，即使展示灯、螺丝刀等其他功能，只要能辨认仍保留黄刻，不把每段都叫展刻字。
- 只露触控笔银色内件，无法辨认原笔颜色款式时省略，不按同批补猜。用户确认`触控笔画线（窗边）`。
- 多个功能都是展示重点时逐项写清，不能只写多功能展示；原表分类仍可叫多个功能展示。顺带可见的刻度、水平仪不自动加入名字。
- 同背景同功能的镜头，可保留真实运镜差别区分；不是每条都加运镜。
- 尺子画线时配合使用的辅助黑笔不写，用户解释每个多功能笔都会有；不扩大为所有道具颜色都省略。

## 已校准叫法与取舍

| 画面 | 命名/规则 |
|---|---|
| 展示开瓶器、手机支架共用缺口 | 两项都写，不写“或”。候选方向`展开瓶器+手机支架（黄+沙发）`，确认的是双功能并写，其他细节未逐字确认。 |
| 实际支撑手机 | 用户倾向`展手机支架（黄+红格桌布）`，省略放手机，不附加开瓶器。 |
| 旋转后抽出触控笔 | `旋转+拔出触控笔（黄刻+沙发）`，保留关键动作顺序。 |
| 拿出、靠近展示刻字 | `拿出+凑近展刻字（黄刻+沙发）`。 |
| 重点展示水平仪 | `水平仪（黄+木板+绿植）`，无需展开气泡移动或顺带刻度。 |
| 沿相框边缘量尺寸 | `尺子测量（黄+相框）`，测量是实际动作，区别于只展示刻度。 |
| 螺丝刀演示后插回笔内 | `拔出+展双头螺丝刀+插回（黄+木桌）`。 |
| 写字后促销展示 | `写+展买一送一（黄+窗边绿植）`，归展买一送一。 |
| 两支黄色刻字笔普通展示 | `双笔展示（黄刻+窗边猫）`，无买一送一字样，归寻常开头。 |
| 明确人物递接并开灯 | `递双笔+开灯（黄黑+沙发）`，归演戏开头。 |

这些例子界定功能、动作取舍：手机支架可概括，旋转+拔出可保留；不要求逐帧罗列，也不一律删动作。

## 分类条件

| 实际内容 | 归类 |
|---|---|
| 普通展示两支黄笔，没有买一送一字样 | 寻常开头 |
| 普通展示一黄一黑，即使无买一送一字样 | 展买一送一 |
| 明确以某项功能为重点，包括黄黑多笔同框演示水平仪 | 对应功能类；本例归水平仪，不因黄黑组合改归促销 |
| 有明确人物递接互动和表演用途 | 演戏开头；人物入镜本身不足以判演戏 |
| 整支笔放回包装，形成展示收束 | 结尾，优先于普通黄黑组合促销判断；可以没有下指 |
| 功能演示中把螺丝刀部件插回笔内 | 螺丝刀功能类，不作为整支产品放回结尾 |

本产品不使用磁吸灯前端/中部/后端分类。功能小节包括笔身/包装、写字笔/笔芯、灯、水平仪、尺子/刻度、开瓶器/手机支架、触控笔、双头螺丝刀、多个功能展示、展买一送一；按当批表的实际名称和颜色款式组落位。

不同批次可按黄色+黄刻、黑色分组，也可直接按功能分组。H/I等列用途会变化，已成片区域不接收原素材。未讨论的双黑笔等组合，不按单个例子补成通用规则。
