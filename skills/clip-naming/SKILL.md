# 片段命名与归档

给新拍的素材起名，名字要让人**一眼知道这段在拍什么**，并按开头/中间/结尾归档到本地文件夹。

## 流程

1. **抽帧看全片**：`scripts/caption_clip.py` 抽帧覆盖整段，一次调用把这一段的帧全部交给视觉模型，输出结构化字段（画面主角/看到的东西/时间线/主体/动作/部位/结果/视角/场景/是否演戏/是否引下单/**简短命名**/把握度）。
2. **起名**：优先用模型给的 `简短命名`（≤12 字），没有才用 `scripts/name_and_file.py` 按词表拼（规则见 `references/naming-grammar.md`）。
3. **分类**：开头（演戏开头/寻常开头）、中间（前端/中部/后端）、结尾，判定规则见 `references/taxonomy.md`。
4. **归档**：把文件**复制**到 `~/Desktop/短视频素材/<拍摄日期>/<分类>/`，文件名为新名字，重名自动加 2、3；随后把**原片移到 `<日期>/_原片存档/`**（用 `--archive`），让「未命名上传」自动清空。
5. **给确认清单**：输出「原文件 → 新名字 → 分类 → 把握度」表格。用户说哪个编号不对就改那一个。

## 硬规则

1. **看完整段再命名**，不能只看一帧（动作是过程：吸住 ≠ 假吸 ≠ 吸出）。
2. **不删除任何素材**：命名 = 复制到分类夹；原片只**移动**到 `_原片存档`（不是删除）。重名加后缀，绝不覆盖。
3. **名字 0–15 字**，用用户自己的词（灯/笔/画 + 吸/展/伸/照…），不要写成一句话。
4. **把握度低于 0.6 的必须单独列出来**让用户确认，不要假装确定。
5. 判断不了就问，不猜；宁可给"待确认"也不要乱命名。
6. **先客观描述画面，不要预设产品是什么**（最重要，见 `references/naming-grammar.md` 开头）。看到指甲油瓶滴胶就写"指甲油瓶滴胶"，绝不硬套成"磁吸灯吸出细钉子"。

## 环境

- **默认走云端**：阿里云百炼 `qwen3-vl-plus`（key 在 `~/.local/opt/clip-naming/dashscope.key`，600 权限；环境变量 `DASHSCOPE_API_KEY` 优先）。云端不用 GPU，Codex 自己就能跑。
- **本机备选**：`~/.local/opt/clip-naming/venv`（mlx-vlm + Qwen2.5-VL-3B-4bit）。**MLX 需要 GPU，Codex 沙箱访问不到 Metal**，只能在用户终端跑（双击脚本）。
- 对比实测（2026-09-17，3 条）：云端更快更准（5.6 秒/条 vs 31 秒/条；云端看出"指甲油滴胶/冒烟"，本机只写"细钉子"）→ **默认云端，本机仅作断网/隐私备选**。
- 成本：qwen3-vl-plus 输入 1 元/百万 token、输出 10 元/百万；一条素材 ≈0.005 元，一条完整成片 ≈0.1–0.3 元；每个模型送 100 万 token（90 天）。

## 用户的工作流（已经搭好，照这个走）

1. **收件夹**：`~/Desktop/短视频素材/<拍摄日期>/未命名上传/`。用户拍完把素材**移动**到这里，之后不要动。
2. 用户双击桌面 **「命名并分类.command」** → 自动跑 `scripts/process_inbox.sh`：
   扫描所有 `<日期>/未命名上传/` → 云端看片 → 起名 → 复制分类 → **原片移到 `_原片存档/`（收件夹自动清空）** → 出 `_命名确认清单.md`。
3. 我（Codex）接手时：读 `_命名确认清单.md`，把"把握度 < 0.6"或用户点名的条目重命名/换分类（用 `mv` 在分类夹之间移动，不删原片）。
4. 迭代产生的旧版本文件先移到 `_回收_XXX_日期/`，确认无用后再按用户意愿丢废纸篓。

## 迭代经验（2026-09-17）

- 模型会**照抄提示词里的示例**（示例时间线被原样复制到 3 个片段）→ 示例必须写成 `<占位符>`。
- 强背景知识会**带偏判断**（提示词写了"磁吸灯吸零件"，它就把指甲油滴胶也说成"吸细钉子"）→ 改成"先说你真看到什么"。
- 让模型自己给 `简短命名` 比事后按字数截断好（截断会切出"按压部""线束插"这种半截词）。
- 画面主角不是产品本身（手/道具/指甲油瓶）时，直接用 `一句话` 当名字，走词表拼装反而更差。

## 首次安装（用户双击一次即可）

桌面 **「安装片段命名.command」** → 跑 `scripts/setup_vision.sh`（建 venv、装 mlx-vlm、下模型 ~2GB、生成 `clip-caption`/`clip-name`）。

如果模型下载中断，重复双击即可断点续传；也可以让我在沙箱里把权重下完（下载不需要 GPU，只有**推理**需要）。
