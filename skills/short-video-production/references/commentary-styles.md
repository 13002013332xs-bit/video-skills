# 解说/文案风格矩阵（思路参考 JJYB_AI 智剪，按我们的流程重写）

需要写解说稿或决定"这条片子用什么口吻"时用。原项目有完整的档位；这里保留对我们有用的部分，
并把默认值调成"跨境电商产品视频"的常用组合。

## 一、先选"视频类型预设"（一键定调）

影视解说 / 动漫解说 / 短剧漫剪 / 综艺娱乐 / 体育高光 / **综合通用** / 纪录片 /
**科技数码** / **美食种草** / 旅行教育 / 自定义

→ **我们默认用「科技数码」或「综合通用」**（产品功能演示、讲参数、讲用途）。

## 二、文稿风格（12 档，选 1 个）

正式 / 幽默 / 激情 / 悬疑 / 情感 / 平和 / 纪录片 / 中二热血 / **爽点密集** / 感官细节 / **叙事白描** / **钩子反转**

→ 带货短视频常用：**爽点密集**（一句一个卖点）、**钩子反转**（先抛疑问再揭晓）、**叙事白描**（老实讲功能）。

## 三、配套的三个旋钮

| 旋钮 | 档位 | 我们的默认 |
|---|---|---|
| 情感基调 | 4 档（平静→热烈） | 中偏热 |
| 解说类型 | 12 档（讲解型/测评型/种草型/剧情型…） | 讲解型 + 种草型 |
| 开头钩子 | 10 档 | "提问式"或"反常识式"（前 3 秒必须抓住） |

## 四、写作人格 + 叙事视角 + 语速 + 情感浓度

- **写作人格**（12 种）：老手/邻居/专家/朋友/段子手… → 产品视频用"**懂行的朋友**"
- **叙事视角**（4 种）：第三人称 / 第一人称 / 内心独白 / 客观 → **第一人称**（"我"）更有代入感
- **语速**（5 档）→ 带货取中偏快
- **情感浓度**（4 档）→ 中档，别喊麦

## 五、几种"叙述风格"的直接用法

| 风格 | 适合场景 | 首句长什么样 |
|---|---|---|
| 直播带货 | 讲优惠、催下单 | "这个价格你们真的别错过" |
| 引导式 | 教用法 | "先这样…再这样…" |
| 吐槽式 | 反常识开场 | "谁还用老办法捡螺丝？" |
| 深度解析 | 讲参数 | "它到底能吸多重？" |
| 影视解说 / 短剧漫剪 | 剧情类素材（我们的"演戏开头"就偏这个） | 一点悬念 + 结果前置 |

## 六、文案质检六维（自己的稿子先过一遍）

写完之后逐项打分（1–5 分），**任何一项 ≤2 分就重写**：

1. **吸引力**（前 3 秒留得住人吗）
2. **节奏**（句子长短交替、没有憋长句）
3. **信息量**（每句是否有新信息，别复读）
4. **情感**（有没有态度，不是说明书）
5. **流畅度**（读出来顺不顺，能不能一口气念完）
6. **原创性**（是否只是把参考视频的话换个说法）

## 七、我们的默认组合（省事版）

```
视频类型：科技数码 / 综合通用
文稿风格：爽点密集 + 钩子反转
情感基调：中偏热   解说类型：讲解型+种草型
开头钩子：提问式（前 3 秒）
写作人格：懂行的朋友   视角：第一人称   语速：中偏快   情感浓度：中
```
