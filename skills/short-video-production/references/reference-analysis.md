# 参考视频拆解与镜头评分

## 拆片（最实用的一步）

1. 下载原片（yt-dlp；抖音/小红书/B站/YouTube 见下节），**保留原声**——如果用户要用它的配音，直接把音轨抽出来做音轨。
2. **按切镜头分镜**：画面切一次 = 一个镜头。逐镜头记录：
   - 画面含义（谁在做什么，动作对象是什么）
   - 时长
   - 该镜头在结构里的作用（钩子 / 展示 / 证明 / 引导下单）
3. 用户口述的结构优先于你自己的推断。当两者冲突，以用户口述为准并复述一遍求确认。
4. 时长总和要等于配音长度；每个镜头的秒数就是后面选素材时的"时长下限"。

## 镜头筛选评分（借鉴 video-expert-analyzer）

需要"从一堆素材里挑最好的镜头"时，用两套现成理论做打分维度：

- **Walter Murch 剪辑六法则**（按重要性排序）：情绪 > 故事 > 节奏 > 视线轨迹 > 二维画面构图 > 三维空间连续。冲突时保前舍后。
- **五维评分**：画面质量、主体清晰度、动作完成度、构图、与镜头的语义贴合度。按场景类型动态调权重（特写重"清晰+动作"，全景重"构图+空间"）。
- 精选片段自动复制到 `scenes/best_shots/` 并在报告里给理由，别只给分数。

**重要限制**：这套打分依赖**多模态（能看图）的模型**。当前环境里我看不到画面，
所以打分只能由用户确认，或退化成客观信号（文件名语义、时长、抽帧相似度）。

## 多平台下载

- 通用：`yt-dlp`（YouTube、Bilibili 等）。
- 抖音 / 小红书：用专用下载器（公开或分享链接通常不需要浏览器 cookie）；B 站可另取官方字幕。
- 网络受限时先申请当轮网络权限，再下载；只下载与任务相关的素材，不要整站抓。
