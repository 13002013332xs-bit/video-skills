# 批量出片的一致性规则（方法参考自 OpenMontage 的 edit-director）

一次出多条时，**每条都能独立看，但整批看起来要像同一个系列**。

## 1. 先锁"整批模板"，再做单条微调

出片前先把这些定死（不要每条各写各的）：

- 字幕样式（字体/大小/位置/描边）
- 钩子出现的时机（第几秒出现文字）
- 角标/水印的出没规则
- 音频淡入淡出长度（我们统一 30ms）
- 转场类型（我们默认硬切，不加花哨转场）

## 2. 前 2-3 秒必须抓人

- 从**动作、结果或产品**开始，不要从"铺垫"开始
- 需要的话第一帧就上钩子文字
- 字幕跟着**第一个说出口的词**出现，不要提前
- 不要为了品牌/logo 把钩子往后推

## 3. 边界要干净

- **不切在词中间**（切点对齐词边界）
- 说到重点后**不留拖尾的静音**
- 不要"为了铺垫而铺垫"
- 片尾卡片要能挣回它的时间，否则删掉

## 4. 常见坑（我们都踩过或差点踩）

- 把多条剪成了一条"合集" → 每条必须能单独发
- 钩子文字 + 字幕 + 水印 + 角标一起堆在屏幕上 → 手机上根本看不清，最多两层
- 整批淡入淡出/转场时长不一致 → 一眼看出是拼的
- 同一素材在整批里反复出现（我们已用**用片台账**解决：`ledger.py`）
