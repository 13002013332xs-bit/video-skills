# 混剪与"音画同步"规则（思路参考 JJYB_AI 智剪，按我们的流程重写）

## 一、最该抄的一条：**不许用定格/重复镜头凑时长**

原项目写得很硬：

- 配音比素材长时，允许的做法只有四种：**直接连接、截取素材高光段、在安全范围内慢放、把过短的语音段合并**
- **新时间线里不许生成 freeze（末帧定格）**
- 素材短到"安全慢放也盖不住配音"时 → **明确报错/拒绝**，不许拿末帧定格伪造时长
- 卡点素材或节拍不够时 → **明确失败**，不许重复镜头补足

**我们的做法**：写进流程——画面不够就**明确告诉你**（"这一拍素材不足，需要补拍"），
不用定格、不用重复镜头、不用拉长到变形来糊弄。

## 二、原片原声穿插（用素材自己的声音）

需要保留一点现场音（机器声、拧螺丝声、胶水滴落声）时：

- 按**比例**穿插：整条片子里原声占比如 15%–25%
- 按**间隔**穿插：每隔 N 个镜头插一段原声
- 选原声的优先级：**同一素材的后继片段 → 时间上相邻的片段**（听着连贯）
- 音量：原声压到配音的 15%–30%，别盖住人声
- **没有合适的可用镜头时，宁可不要原声**，不要复用同一条素材

## 三、混剪两种模式

| 模式 | 做法 | 什么时候用 |
|---|---|---|
| **普通混剪** | 批量分镜 → 按画面评分挑高光 → 按配音时长逐段匹配 | 有配音、要讲清功能 |
| **音乐卡点** | 用 BGM 的节拍和能量切点，三档密度（密集/适中/稀疏），高潮段可轻微慢放 | 纯展示、无口播 |

## 四、节奏包（按内容选一个，整批统一）

标准混剪 / **音乐卡点快切** / 高燃预告 / 剧情递进 / 游戏高光 / Vlog 流动 /
**产品展示** / 知识拆条 / 旅行蒙太奇 / 美食特写 / 萌宠反应 / 舒缓蒙太奇

→ 我们做产品视频默认 **产品展示**（或卡点快切）；同一条片子里不要混用两套节奏。

## 五、时长要"算"出来，不是估出来

- 定目标时长后，**按节拍数反推**每段该多长
- 出片后用 ffprobe **校验实际时长**，与配音对齐（我们已有的规则：总长=配音长度、无空洞）
- 差得太多说明素材或节拍不够 → **报错让你决定**，不要偷偷拉伸

## 六、参考节奏匹配（跟我们"看参考视频"是一回事）

从参考视频里提取的是：**节奏点（切点密度）+ 每拍的镜头描述**，
然后拿这两样去素材库里找"节奏对得上、画面也对得上"的镜头；
匹配没把握的列成**"低置信清单"**给你确认，而不是硬选。
