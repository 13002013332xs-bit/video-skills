# 参考视频拆解：五维度 + 运动类型（方法参考自 OpenMontage 的 video-reference-analyst）

拆参考视频不要只写一段散文。**每个镜头按下面 5 个维度逐条过**，下游（选片、脚本、剪辑）才能直接用。

## 五维度（逐镜头）

1. **主体（Subject）**：是什么、几个、有什么特征（颜色/材质/新旧）；跨镜头的变化（出现 / 消失 / 切换 / 交替）
2. **主体动作（Subject Motion）**：按时间顺序的动词；是单人动作还是配合动作；是移动、手势还是表情
3. **场景（Scene)**：**文字/贴纸/水印单独列一层**（不要混进环境描述）；视角（俯拍 / 微距 / 顶视 / 手持 / 固定）；环境；时间/光线；动态元素（烟、水、飘落物）
4. **空间构图（Spatial Framing）**：景别（特写/近景/中景/全景）；主体在画面中的位置；前后景层次；机位高度（高于/平于/低于主体）；以及这些在镜头内**怎么变化**
5. **摄影机（Camera）**：速度（正常/慢动作/延时）；镜头畸变；高度；角度（俯/仰/斜）；对焦（跟焦/大景深/浅景深）；稳定（固定/手持/云台）；运动（推/拉/摇/跟随）

## 运动类型判定（很重要，别猜）

每个镜头标一个类型，决定我们怎么复刻：

| 类型 | 含义 | 我们怎么复刻 |
|---|---|---|
| `motion_clip` | 真实拍摄的动态镜头 | 从素材库找同类动作片段（我们的主路径） |
| `animated_still` | 静图 + 推拉（Ken Burns） | 选一张素材图 → 加缓慢推近 |
| `static_image` | 完全静止画面 | 图 + 文字层 |

判错会导致整条片子的做法都错，**必须靠实际抽帧看，不能凭印象**。

## 给用户看的摘要格式（固定这样写）

拆完先讲给用户听，**按这个结构**（不要贴原始数据）：

```
我看完了。这是我看到的东西：

**内容**：两句话说清这条片子讲什么
**风格**：一句话说节奏/画面处理/能量感
**结构**：X 个镜头 / 共 Y 秒 / 节奏是怎么样的
**运动**：M 个镜头里 N 个是实拍动态 / 静图推拉 / 静止图
**五维度逐拍**：主体 / 主体动作 / 场景（含文字层）/ 空间构图 / 摄影机
**它为什么有效**：2-3 条具体的（钩子怎么做的、节奏、转场、口播方式）
```

然后才进入"我能用你现在的素材做到哪一步"。
