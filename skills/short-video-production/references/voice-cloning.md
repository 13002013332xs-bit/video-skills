# 语音克隆 / TTS（怎么做、走哪条路、红线在哪）

## 一、先明确要不要用

- 用户**自己提供配音**时 → 直接用它，不需要克隆（我们默认流程就是这样）
- 需要"**用某个音色批量生成配音**"时（例如统一音色、多语言版本）→ 才需要克隆
- ⚠️ **红线**：克隆**别人**的声音（达人、客户、明星）必须拿到本人**书面授权**；
  克隆**自己**的声音没问题。这条没有例外。

## 二、三条路线（按省事程度）

### 路线 A：云端 API（最省事，按量付费）

| 服务 | 说明 |
|---|---|
| **小米 MiMo**（推荐，国内） | 提供 TTS / **声音克隆** / 声音设计 / ASR；有开源 MCP 封装（mimo-mcp，MIT），**Codex 可直接当工具调用**；音色库本地存 SQLite，克隆一次到处用 |
| MiniMax / Fish Audio / 火山引擎 | 都有声音克隆，价格与效果各有差异 |
| Azure Custom Voice | 企业级，需申请，合规流程较严 |

路线 A 的接法：在 <https://platform.xiaomimimo.com/> 拿 API key → 用 MCP 或直接调 HTTP → 我们脚本里按"文本→音频"调用。

### 路线 B：本地克隆（免费、私密、要显卡/内存）

| 项目 | 特点 |
|---|---|
| **voice-pro**（★12.8k, GPL-3.0） | Gradio 界面，内置 **F5-TTS / CosyVoice / E2** 零样本克隆 + Whisper，模型较多 |
| **clone-voice**（★9k，中文社区） | Web 界面，中文效果不错，安装简单 |
| **IndexTTS2** | 中文音色克隆效果好，需独立 Python 3.10 环境 |

代价：要下几 GB 模型权重；Apple Silicon 上速度一般；装环境比较折腾。

### 路线 C：不克隆，用现成 TTS（最快）

Edge TTS / gTTS（免费、秒出，音色固定）——适合"只要求清楚、不要求特定音色"。

## 三、我们的默认建议

| 场景 | 用哪个 |
|---|---|
| 用户给了配音 | **直接用**，不折腾 |
| 要统一音色、量不大 | 路线 A（MiMo 之类） |
| 不想上传、要私密、量大 | 路线 B（本地 clone-voice / voice-pro） |
| 只要清楚、不在乎音色 | 路线 C（Edge TTS） |

## 四、用克隆音频时的注意

1. 生成的配音**语速/停顿**要跟画面对齐（我们按词级时间戳对齐，规则见 `mixing-rules.md`）
2. 配音长度决定成片长度 → **总长 = 配音长度、画面不许定格凑时长**
3. 克隆出来的音频要**试听后再批量生成**（避免整批跑完才发现音色不对）
4. 授权文件/对话留档：谁授权、授权范围、时间
