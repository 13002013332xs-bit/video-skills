# 多视频结构挖掘 → 自动出脚本

**用途**：手里有 N 条同类爆款（同一产品/同一类目），要把它们的**共性**提炼出来，再照着共性生成自己的脚本。

## 一、输入什么

每条参考视频先跑一遍拆解（`scripts/analyze_reference.py`），得到：

- **画面结构**：分镜表（每拍的作用/景别/运镜/一句话）
- **脚本**：本地转写（词级时间戳）

## 二、怎么提炼共性

对每条视频先**归一化**成统一结构表（每段：作用 / 占比 / 画面要点 / 口播要点 + 钩子类型 + 卖点顺序），再横向统计：

| 统计项 | 看什么 |
|---|---|
| **各段占比** | 钩子占几秒？功能演示占多少？价格段在第几成位置？ |
| **固定顺序** | 大多数视频是不是"钩子 → 实证 → 功能 → 场景 → 价格 → 收尾" |
| **钩子类型** | 提问式 / 反常识 / 结果前置 / 故事式，哪种出现最多 |
| **卖点顺序** | 先讲什么后讲什么（例如先"吸力"再"照明"再"价格"） |
| **画面要求** | 每个卖点对应什么镜头（特写？实拍？对比？） |

## 三、生成脚本时叠加的三层规则

1. **共性结构**（上面统计出来的骨架）——决定"第几拍讲什么"
2. **文案原则**（营销文案通用法则）：
   - **清晰优先于花哨**——看不懂就输了
   - **讲利益不讲功能**（"4 小时报表缩到 15 分钟" > "支持自动报表"）
   - **具体压倒模糊**（数字、场景、品牌名）
   - **用客户的话**，不用公司的话
   - **一段一意**——每个镜头只推进一个论点
3. **风格矩阵**（见 `commentary-styles.md`）——决定口吻、钩子类型、人格

## 四、我们怎么落地

脚本：`scripts/mine_structures.py`

```bash
python mine_structures.py <视频1目录> <视频2目录> ... --out <输出目录>
# 输出：structure_report.md（共性报告）+ normalized_structures.json（归一化结果）
```

**实测**（下水道版 + 圣诞达人版两条参考片）产出：

```
## 一、共同结构
固定顺序：结果前置钩子 → 磁吸实证 → 伸缩调角 → 柔性穿缝 →
          强光细节 → 多场景组合 → 信任收尾

## 二、最有共性的 3 个钩子
1. "两分钟解决XX难题"式结果前置
2. "专为XX人群设计"身份锚定 + 功能浓缩
3. "反常识操作"引发好奇（不用拆件/不用伸手）

## 三、共性卖点顺序 + 画面要求
磁性吸附 →（吸起瞬间特写）｜伸缩调角 →（拉伸+暗转亮）｜
柔性穿缝 →（弯 90° 进窄缝）｜强光显细 →（微距+字幕）｜
解放双手 →（磁吸立起+双手操作）｜价格 →（拆解+价格牌）

## 四、可直接套用的脚本模板
0:00–0:04 | 近景：伸缩+磁吸头吸起金属件 | "两分钟，不用掏不用拆…"
```

## 五、用的时候注意

- **至少 3 条**参考视频才叫"共性"（2 条只能说"相似"）
- 共性里的"固定顺序"是**参考，不是铁律**；你有明确要求时以你的要求为准
- 生成脚本后**跑一遍六维质检**（吸引力/节奏/信息量/情感/流畅度/原创性，见 `commentary-styles.md`）
- 脚本里的每一拍都要能对应到**你素材库里真实存在的画面**（对不上就走 `material-gaps.md`）
