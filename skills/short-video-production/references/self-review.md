# 出片自检协议（方法参考自 OpenMontage 的 reviewer skill）

**每一支出片前后都要过这一关**，标准是"能指出具体位置 + 给出可执行的修改"，不是打个分。

## 批评的三条硬标准

1. **准确**：每条问题必须指到**具体的第几拍 / 哪一帧 / 哪个文件**。指不出来 = 在猜，不许写。
2. **完整**：发现一个问题后，**把同类问题全扫一遍**再返回（例如"第 8 拍太暗"，就要把 15 拍全过一遍亮度）。
3. **可执行**：每条"严重"问题必须附**具体改法**（换成哪条素材 / 时长改成几秒 / 加什么文字）。给不出改法的，只能标成"待查"，不许标成"严重"。

## 严重度分级

| 级别 | 含义 | 是否必须处理 |
|---|---|---|
| **严重** | 结构错、素材不符、时长对不上配音、空洞、素材丢失 | 必须改，且必须附改法 |
| **建议** | 明显影响观感（太暗、节奏拖、主体不清） | 应改，附改法 |
| **细节** | 锦上添花（字体大小、淡入时长） | 可改可不改 |
| **待查** | 有问题但一时说不清怎么改 | 下一轮再看，不阻塞 |

## 决策表

| 情况 | 动作 |
|---|---|
| 0 个严重 | **通过**，把建议记下来 |
| ≥1 个严重 | **返工**，改完再审（最多两轮） |
| 两轮后仍严重 | **带警告通过**，把未解决的列给用户，不要无限卡住 |

## 具体做法（我们这条流水线）

1. 成片每一拍抽 1 帧 → 交给视觉模型，对照"这一拍该表现什么"打分 + 挑毛病
2. 分数 **<0.6 的拍全部列出来**，逐条给改法
3. 能自动改的（换素材 / 调时长 / 加文字）直接改；改不了的（要补拍、要圣诞氛围）**明确写进报告让用户决定**
4. 自检报告和成片一起交付，格式：`时间 | 素材 | 分 | 问题 | 改法`
