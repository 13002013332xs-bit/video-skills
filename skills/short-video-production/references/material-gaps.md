# 素材缺画面时怎么办（方法参考自 OpenMontage 的 broll-planning）

当某一拍找不到合适画面时，按这个顺序决策，不要拿不相关的素材硬凑。

## 1. 先用我们自己的素材库（永远优先）

- 类别锁定 + 关键词 + **用片台账**（优先没用过的）→ `pick_fresh.py`
- 用视觉模型给候选**打分**，挑最贴合参考画面的 → 见 `pick_verified.py` 的做法
- 都不到 0.6 分 → 说明这条素材撑不起这一拍，走下面几步

## 2. 判断该补拍、该生成、还是该换表达

| 这一拍需要 | 优先做法 |
|---|---|
| 真实场景/真人/真实产品细节（车底、发动机、手部动作） | **补拍**（AI 生成的真实场景容易假） |
| 抽象概念、示意图、数据可视化 | **生成图/图表**（比找素材准） |
| 氛围镜头（光线、烟雾、水、粒子） | **素材库/生成都行**，看哪个快 |
| 品牌风格插画、卖点卡片 | **生成**（能对齐品牌调性） |
| 历史/档案画面 | 素材库 |

一句话：**要"真"就补拍或找素材；要"准"（抽象概念）就生成。**

## 3. 找不到就换表达（最快的解法）

- 把这一拍的长镜头**拆成两条短素材**（我们已经在用）
- 用**文字层**替代画面（例如价格/优惠券，我们已给 $30/$20/$9.99/-50% 加文字）
- 把这一拍的时长**让给相邻拍**（时间轴重分配，总长不变）

## 4. 报告给用户（不要默默凑合）

自检报告里明确写：

```
第 X 拍（时间）需要：<画面描述>
现状：候选最高只有 0.XX 分
建议：补拍（说明要拍什么）/ 生成 / 加文字 / 接受
```

我们的原则：**素材撑不起就直说，宁可少一拍也不要拿不相干的画面糊弄。**
