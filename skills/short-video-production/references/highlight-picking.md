# 高光片段选取（思路参考开源 highlight detection，按我们的流程重写）

**用途**：从长素材（几分钟）里自动找出"最值得用进成片的 2–6 秒"，不用整段看。

## 一、判断"是不是高光"的 8 类信号（按影响力排序）

1. **钩子时刻**——一句话/一个动作让人立刻好奇
2. **情绪峰值**——惊喜、笑、惊讶、紧张的真实反应
3. **观点炸弹**——反常识、会引起"同意/反对"的表达
4. **揭示时刻**——结果揭晓（零件被吸出来、价格牌出现）
5. **冲突/张力**——问题被正面解决的那一下
6. **金句**——能单独当字幕卡的短句
7. **故事高潮**——一段演示的 payoff
8. **实用价值**——观众能立刻用上的技巧

> 带货产品素材里，最常命中的是 **1（钩子）、4（揭示）、8（实用）**。

## 二、选取规则（硬性）

- **前 3 秒必须有钩子**（如果这段要当开场）
- **不切在半句话/半个动作中间**——每段必须自成一体
- 段与段**不要重叠**；重叠的只留分数高的
- 打分是"**爆款潜力**"0–100，不是"画质好坏"
- 每段要能说出**为什么值得用**（说不出就别选）

## 三、长素材怎么处理

- 按 **20 秒一块**切开评估（长视频才不会漏掉中间段）
- 相邻块留 **60 秒重叠**（防止高光刚好被切在块边界）
- 全部候选按分数排序 → **重叠抑制**（保留高分的，丢掉被覆盖的）

## 四、我们怎么落地

脚本：`scripts/pick_highlights.py`

```bash
python pick_highlights.py <长素材> --chunk 20 --top 3
# 输出：<素材名>.highlights.json  [{start, end, score, what, why}]
```

实测（18 秒素材，按 10 秒分块）：

```
 1.5– 3.5s  分 92  伸长灯照引擎舱 —— 动作完整（伸长+开灯）、结果可见、突出照明卖点
12.8–15.6s  分 92  灯照钥匙亮掌心 —— 动作完整、强光打亮手掌与钥匙、突出照明卖点
```

**和现有流程怎么配合**：

1. 素材多/素材长 → 先跑 `pick_highlights.py` 找高光窗口（省掉整段看的时间）
2. 选片阶段 → `pick_fresh.py`（类别+关键词+台账）+ 视觉打分（`pick_verified.py` 的做法）
3. 定入出点时 → 优先用高光窗口的 start/end，而不是从 0.3 秒硬切
4. 自检 → `review_own.py` 看这一段实际有没有把高光放进去
