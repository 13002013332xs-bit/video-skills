# 剪辑视频与素材命名

此项目包含两个独立技能，按需要安装；其他项目技能仍在仓库原目录维护。

| 技能 | 入口 | 用途 |
|---|---|---|
| clip-naming | [命名技能](../../skills/clip-naming/SKILL.md) | 整体命名原则、产品选择、对应功能词及细分类、持续学习 |
| short-video-production | [剪辑技能](../../skills/short-video-production/SKILL.md) | 配音拍点、真实素材分类选片、原片草稿、预览与独立验收 |

## 分享与安装

可直接把仓库链接发给对方，让其用自己的Codex按需要安装 `skills/clip-naming` 与 `skills/short-video-production`，也可下载仓库ZIP后将完整技能文件夹交给Codex安装。已有同名技能先备份，并合并自己的规则；不要只复制SKILL.md而漏掉references。

可将下面这段发给对方：

> 请用skill-installer从仓库13002013332xs-bit/video-skills安装skills/clip-naming和skills/short-video-production；已有同名技能先备份，保留我自己的规则。安装后读取命名技能，开始时让我选择产品。

## 命名入口

说“使用 $clip-naming，开始命名”即可；本轮已说明产品时直接使用对应规则，否则从 [产品清单](../../skills/clip-naming/references/products.json) 选择：磁吸灯、多功能笔、肌理画、多功能锤或新增产品。

整体原则：主要功能/动作+关键后续动作或结果，必要时用款式、物品特征、背景、运镜和景别区分相似素材。磁吸灯和多功能笔包含原作者实片校准后的个人风格，可直接沿用；肌理画仅原表观察，多功能锤待学习。接收者自己的当次要求和后来纠正优先，新增产品建立独立参考并加入同一清单。

## 首次准备

使用接收者自己的素材目录与输出位置。全段看片可使用当前环境可用的视觉工具或有效分析缓存，不要求仅命名就安装剪映/离线模型。仅当使用相应旧脚本时才准备它实际需要的依赖。

飞书上传是可选交付，需要接收者自己的登录权限、目标表及任务授权；本包不包含原作者素材、飞书表标识、登录凭据、云端密钥或私有上传脚本。单纯说开始命名不会自动上传。

剪辑技能包含近期生产规则，旧脚本没有全部接入新优化；接收者按技能边界检查工具，不把文档更新当成所有脚本已跨电脑实测。旧桌面命名程序同样不作为多产品入口。
