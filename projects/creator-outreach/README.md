# 找达人项目

所属技能：`tiktok-dm-outreach`，安装目录：`skills/tiktok-dm-outreach/`。

## 分享与安装

可直接发送“找达人项目-分享包.zip”，接收者解压后会得到 `tiktok-dm-outreach/` 和分享说明。把整个技能文件夹放进自己的 `~/.codex/skills/`，不要只复制SKILL.md；已有同名技能先备份再更新。也可把解压路径交给Codex，请它安装这个本地技能。

在Codex中输入：

> 使用 $tiktok-dm-outreach，开始找达人。先让我选择店铺，显示对应商品和图片，再连接我有权限的紫鸟店铺。

如果从GitHub安装，告诉Codex使用skill-installer从本仓库的 `skills/tiktok-dm-outreach` 安装。仓库尚未同步到目标版本时使用最新分享ZIP，不能把旧远端版本当最新版。

## 首次使用准备

接收者需要自己的Codex环境、紫鸟及有权操作的店铺登录，并在其环境安装或连接紫鸟控制工具（例如ziniao-store、ziniao-page对应的CLI/Bridge）。本包提供流程、面板和辅助脚本，不附带登录会话、控制端口或设备权限。电脑TikTok网页版用于内容复核；手机私信属于另行安排的流程。

选定店铺后代理先建立可控窗口，再由使用者设置后台筛选；每轮选择快速筛选或内容复核、PPS，并填写自己的邀请文本、紫鸟私信、商品佣金及样品方式。实际邀约与私信按当前任务明确授权执行。

共享包含明确授权的店铺商品名称、ID、图片及展示价格；不含账号凭据、邮箱、真实话术、佣金、达人名单和台账。商品目录可按店铺继续补充，不混用不同店铺数据。
